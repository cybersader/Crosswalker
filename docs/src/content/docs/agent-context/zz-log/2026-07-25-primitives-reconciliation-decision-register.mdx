<Aside type="caution" title="This is a decision register, not a decision">
A **decision register** is a working log of open choices — what was found, what the options are, what each one costs. Nothing in it is policy until the owner ratifies it. This particular register (the log tracking proposed upgrades to the core building blocks every imported note is made of) went through an independent verification pass (every claim re-derived from the repo; two were corrected before landing here) and a corpus investigation against the actual first-party sources (NIST CPRT, SP 800-53/53A, CSF 2.0, CRI Profile 2.2, SCF 2026.1, CTID/D3FEND packs). Decisions are grouped into three gates: **Gate 1 — schema fields**, **Gate 2 — cleanup**, **Gate 3 — language**. Nothing here is settled until each decision is ratified.

For an executive-readable version of every decision below — plain-English title, tradeoffs, and a recommendation — see the [owner review queue](/crosswalker/agent-context/zz-log/2026-07-25-owner-review-queue/) (the single checklist of everything awaiting the project owner's ratification). This page is the evidence; that page is the decidable surface.
</Aside>

## Verdict in one line

The engine-level primitives survive adversarial audit — two are genuinely novel — but the essence claim ("encoding meaning, not importing tables") currently fails at a handful of missing **fields** in Tier 1 (the canonical Markdown-plus-frontmatter form every imported note takes, and the layer that has to be trustworthy for audit), the closed-grammar commitment has drifted into five contradictory counts, and the complexity worth removing lives in the vocabulary layer, not the code.

## What was validated (do not relitigate)

| Validated strength | Why it held |
|---|---|
| **Junction notes are reified statements, done better** | A junction note is one relationship ("control X maps to control Y") stored as its own file. Independent reinvention of the RDF-reification / Wikidata-qualifier move — but as addressable, git-diffable, human-reviewable files. No established formalism has that combination. |
| **Identity-before-render hashing** | `concept_cid` (the fingerprint that says "this is the same concept regardless of where it sits in a folder tree") hashes `{curie, scope}` before layout. Two vaults with different folder trees are provably the same knowledge. |
| **Mandatory provenance on every node** | Every note records where it came from. Stronger than RDF (optional) and SSSOM (mappings only). |
| **Explicit closure with recorded depth** | `closure_cache.shortest_depth` records how many relationship hops a derived fact took — beats opaque OWL entailment for audit. |
| **`managed` / `user_preserve` split** | The declaration of which parts of a note the tool owns and which belong to the user. The entire re-import safety property. 18 of 19 shipped recipes declare it. |
| **Two edge models (crosswalk-edge vs junction-note)** | A crosswalk edge is a compact row-shaped mapping; a junction note is the same relationship as a reviewable file. The complexity is in the standards they feed (STRM/SSSOM vs OSCAL), not in Crosswalker. |
| **The two existing digests stay orthogonal** | `concept_cid` (same concept?) × `effective_target_hash` (did output-affecting behavior change?) produce the 2×2 that makes drift diagnosable. Merging them collapses it to one bit. |
| **AJV as the pre-write gate** | The schema validator that runs before anything is written to the vault. The reason an external producer or agent is first-class without a code change. The actual moat. |

## Gate 1 — schema fields (Tier 1 field completions)

All additive, all optional, none opens the closed layout grammar or adds an artifact noun. Each decision appears as an executive decision card — plain title, tradeoffs, recommendation — in the [owner review queue](/crosswalker/agent-context/zz-log/2026-07-25-owner-review-queue/) (the single checklist of everything awaiting the owner's ratification) § 1a.

| # | Decision | Corpus evidence | Options | Connects to |
|---|---|---|---|---|
| **P1** | **Ordinal field.** An optional string encoding position-within-parent (dotted, zero-padded path). Sub-decision: does it join `concept_cid` (the fingerprint that identifies a concept independently of where it lands in a folder tree)? | First-party: CPRT ships a dedicated `sort` element per concept; 800-53A ships `sort-as`; CRI ships `Outline Id`. Generated CSF vault currently renders DETECT before GOVERN | (a) adopt, excluded from `concept_cid`; (b) adopt, included; (c) defer | [Target-structure synthesis](/crosswalker/agent-context/zz-log/2026-05-04-target-structure-synthesis/) (commits to lexical-sort canonicalization — must be amended); [View shapes](/crosswalker/concepts/view-shapes/) (deferred timeline shape); `spec/tier1.schema.json` |
| **P2** | **Identity-typed edge endpoints.** Optional `subject_curie` / `object_curie` on junction notes (each junction note stores one relationship as its own reviewable file); `parent_curie` as the schema-blessed hierarchy carrier. Wikilinks remain the rendered affordance | Address-shaped parents currently return null in Tier 2 identity resolution | (a) add optional identity fields (makes the docs' own invariant true); (b) keep address-only and fix the docs claim | [Hierarchy primitives](/crosswalker/concepts/hierarchy-primitives/) ("identity, not address"); `spec/tier1.schema.json`; `src/tier2/projector.ts` |
| **P3** | **Mapping-set identity + negation + version.** Promote `mapping_set_id` (which published crosswalk release an assertion came from, e.g. NIST's 800-53 Rev 4 to Rev 5 mapping) from unmodeled passthrough into the contract and Tier 2 (the rebuildable SQLite projection used for querying); add `predicate_modifier: NOT` (an explicit "these two are **not** equivalent" assertion); populate ontology version | The SSSOM path already writes and round-trips `mapping_set_id`; the NOT modifier was the stated reason SKOS was rejected; r4/r5 silently collide today | (a) all three now; (b) `mapping_set_id` + version now, NOT with the MappingSet envelope | [v0.1 schema spec](/crosswalker/agent-context/v0-1-schema-spec/) (declares the modifier the schema lacks); [SKOS registry page](/crosswalker/reference/registry/skos/) (gap #4); [v0.1.7 milestone](/crosswalker/reference/roadmap/milestones/v0-1-7-exporters/) |
| **P4** | **Legalize facet/hub.** Schema branches for the two note kinds the code already emits (a **facet** note is a slice of the graph, e.g. every control carrying one theme; a **hub** note is an index page for a level), plus write-time validation on hub paths | Hub/facet notes currently bypass `validateTier1Frontmatter` entirely | (a) add branches + validate; (b) constrain `kind` to a closed enum on the concept branch too | [Artifact roles and authority](/crosswalker/concepts/artifact-roles-and-authority/) (the anti-noun rule these kinds currently violate); `src/generation/enrich.ts` |
| **P5** | **Edge groups.** Optional `group_id` marking the members of one joint-coverage conjunction ("A is covered jointly by B, C and D"), plus an importer guard on multi-target `equal` | CRI "Full Summarily": 1,478 rows where conjunction is a published predicate (3:1 majority in three mapping sets); CRI FCS is group-scoped by definition; **10 multi-target `equal` groups are already materialized as logically false pairwise equivalences in the test vault** | (a) `group_id` + guard now; (b) guard only, `group_id` with the MappingSet envelope; (c) nothing — ships a known correctness bug | [STRM registry page](/crosswalker/reference/registry/strm/); [Terminology](/crosswalker/concepts/terminology/); `src/import/sssom-importer.ts` |
| **P6** | **Predicate characteristics registry.** A small vocabulary table declaring `inverse_of` / `symmetric` / `transitive` per predicate | Gives closure a principled stopping rule; ends per-query "check both directions" conventions | (a) now, for the STRM six; (b) with `graph_edges` in v0.2 | [Ontology-web querying](/crosswalker/concepts/ontology-web-querying/); `src/tier2/` closure |

**Resolved by corpus evidence (no longer open):** `graph_edges` stays **reserved for v0.2**. The corpus holds roughly 20,000 non-STRM edges (`mitigates`, D3FEND's 20-plus object properties, CTID impact types, CPRT lifecycle relations), but the vocabulary is open-ended and entangled with unresolved version-lineage design — wiring it now would freeze a vocabulary before the design exists. v0.1's honest carriers are named managed frontmatter conventions (800-53 `Related Controls`, `mitigates`) plus junction-note predicate strings, stated plainly in the schema spec.
