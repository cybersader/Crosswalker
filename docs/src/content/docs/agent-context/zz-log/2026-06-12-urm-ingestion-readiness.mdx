## The sorting rule

Per the [2026-06-02 decision](/crosswalker/agent-context/zz-log/2026-06-02-grc-corpus-end-to-end-use-case/): **format decides ingestability, not framework**. So the checklist sorts by *distance from the floor*, not by framework importance:

1. ✅ **Ingested** — through the production `render()` already
2. 🟢 **Ready now** — structured file held + reader exists; only a recipe is missing
3. 🟡 **Needs the JSON reader** — structured file held; the planned iterator-path reader unblocks it
4. 🟠 **Needs a new adapter** — structured (YAML / XML) but no reader branch exists
5. 🔴 **Below the floor** — prose PDF/HTML; needs a bridge step or the STRM proxy

## Recommended order

1. ✅ **JSON reader** — *done 2026-06-12* (`--iterator` + `--where`; ATT&CK + CPRT smoke-verified)
2. ✅ **CIS v8.1.2 + SCF recipes** — *done 2026-06-12* (153 safeguards + 1,468 SCF controls into `_licensed/`; the melt extractor landed same-day — see item 5)
3. ✅ **CRI → CSF extractor** — *done 2026-06-12* (the mapping sheet was OLIR-shaped; 154 edges via `--header-row` + column aliases; triangle complete)
4. ✅ **Direction snag + padding fix** — *done 2026-06-12*. (a) SKOS→STRM map was inverted (a real bug, not a convention) — flipped in `src/import/sssom-importer.ts` + the tool mirror, pinned by a unit test, all 3 edge sets regenerated; committed SSSOM TSVs unaffected (SKOS is the wire format). (b) `--depad` canonicalizes OLIR's `AC-01` → `AC-1`; `--subject-note-folder`/`--object-note-folder` emit folder-qualified `subject_note`/`object_note` wikilinks → **7,732 links, 99.5% resolve**. CSF function/category notes back-filled from CPRT (`nist-csf-2-cprt.json`) to catch hierarchy-level mappings. Residual 16 unresolved ids are genuinely-absent concepts: 3 family-level 800-53 refs, IA-13 (r5.1.1, newer than our source), and ~11 **CRI v2.2 extension ids masquerading as CSF ids** (`EX`, `GV.AU-*`, `GV.RM-08/09`, `PR.PS-07`) — do not stub these as CSF notes
5. **CTID mapping-pack adapters** (threat→control edges; feeds the Control lens)
6. ✅ **SCF mapping-column melt** — *done 2026-06-12*: `tools/crosswalk-from-melt.ts` → 5,675 edges / 7 frameworks in one pass; ISO + SOC 2 + PCI now reachable as STRM-proxy edges (§5 mostly retired). PCI also got proxy edges (1,218), supplementing the §2 structured door
7. ✅ **Wizard XLSX + JSON wiring** — *done 2026-06-12* ([UI parity audit](/crosswalker/agent-context/zz-log/2026-06-12-ui-parity-audit/) gap #1): sheet picker + header-row offset (XLSX), iterator + row-filter inputs (JSON); shared JSON core moved into `src/`, harness imports it
