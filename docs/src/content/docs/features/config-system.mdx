Crosswalker remembers your [saved configurations](/crosswalker/agent-context/ui-lexicon/) so you don't have to reconfigure columns every time you import a similar file. A saved configuration is a snapshot of the decisions you made in the [import wizard](/crosswalker/features/import-wizard/): which column is what, where notes land, and how they're named.

## Saving a configuration

Save the current configuration from the config browser (see below) any time during or after mapping a source. Each saved configuration stores:
- Column-to-role mappings
- Output path and naming settings
- A fingerprint of the source data structure, used for [matching](#config-matching) against future files

## Config matching

When you select a new file, Crosswalker generates a fingerprint and scores it against your saved configurations. If a match is found above the threshold (default: 50%), the wizard suggests applying it.

Matching considers:
- Column name overlap
- Column count similarity
- Data pattern similarity (when pattern detection is enabled)

## Config browser

Open it from the workspace tab's launchpad ("Manage saved configs"), the settings hub, or the wizard's suggestion banner. You can:
- Browse all saved configurations, with search and sort
- Expand a card to preview its column mappings, fingerprint, output path, and last-used date
- **Duplicate** a configuration (a starting point for a close variant)
- **Delete** outdated configurations
- **Export** any configuration to a downloadable JSON file, and **Import** one from a JSON file — the shareable unit for handing a teammate "here's how to import this framework's spreadsheet," or carrying a configuration between vaults

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Enable config suggestions | On | Show "Use this config" prompts |
| Match threshold | 50 | Minimum score (0-100) to suggest a config |
| Pattern detection | On | Detect data patterns for smarter matching |
| Auto-apply exact match | Off | Skip confirmation on 100% match |
