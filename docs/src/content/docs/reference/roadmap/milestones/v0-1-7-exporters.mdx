## Goal

Make the user's [Tier 1](/crosswalker/concepts/terminology/) vault data portable. Three target formats for v0.1 — [STRM](/crosswalker/reference/registry/strm/)-shaped TSV (the user-facing wire format from [NIST IR 8278A r1](/crosswalker/reference/registry/olir/) OLIR template), [OSCAL](/crosswalker/reference/registry/oscal/) JSON profile (for compliance-tool interop), and [SSSOM](/crosswalker/reference/registry/sssom/)-flavored TSV (optional, for academic interop). Hybrid SSSOM↔STRM resolution per [v0.1 stack pivot §6](/crosswalker/agent-context/zz-log/2026-05-02-v0-1-initial-stack-pivot/).

## Status

🚧 In progress (started 2026-07-12) — first slice landed: exporter engine + two palette commands. Delivery detail lives in `CHANGELOG.md` `[Unreleased]` ("Vault-wide connection defaults + export lands").

## Dependencies

- [v0.1.5 — Tier 2 sidecar](/crosswalker/reference/roadmap/milestones/v0-1-5-tier-2-sidecar/) (joins, coverage matrices, deduped exports use sidecar queries)

## Scope

**In:**
- STRM-shaped TSV exporter — produces NIST IR 8278A r1 OLIR template format; Excel-friendly
- OSCAL JSON profile exporter — emits the `Control Mapping Model` shape; isomorphic to junction notes per [Ch 07 synthesis](/crosswalker/agent-context/zz-log/2026-04-10-evidence-link-edge-model-synthesis/)
- SSSOM-flavored TSV (optional, opt-in) — for users who want to share crosswalks with the SSSOM academic ecosystem
- CSV exporter — any generated framework folder back to a spreadsheet (scope addition, delivered 2026-07-12 ahead of plan)
- Command palette entries: "Crosswalker: Export STRM TSV", "Export OSCAL profile", "Export SSSOM TSV"
- Roundtrip test: STRM TSV → import → STRM TSV produces identical bytes (deterministic)

**Out:**
- OSCAL catalog export (deferred to v1.0+)
- Compliance dashboards / report generation (community phase)
- AI-assisted mapping suggestions (community phase)

- [ ] STRM TSV opens cleanly in Excel; column ordering matches NIST IR 8278A r1
- [ ] OSCAL JSON profile validates against the OSCAL JSON Schema (NIST published)
- [ ] SSSOM TSV passes the `sssom-py` validator (optional CI step)
- [ ] All three exporters handle large vaults (~10K mappings) without UI freeze (cooperative yielding)
