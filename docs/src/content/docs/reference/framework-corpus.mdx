This page catalogs the corpus of **security and GRC frameworks** pulled for realistic crosswalking — scoped to Crosswalker's launch problem domains: **cybersecurity, information security, governance/risk/compliance (GRC), risk management, internal audit, and regulatory compliance**. For each file: what it is, whether it's safe to commit, and which files are *not actually frameworks or ontologies* and can be cut. Pair it with [framework data sources](/crosswalker/reference/framework-data-sources/) (parsing details: sheets, columns, ID formats) and the [registry](/crosswalker/reference/registry/) (each framework's home page).

<Aside type="note" title="Scope">
This is **not** a general framework catalog — every entry sits in the security/GRC/risk/audit space (NIST, MITRE, CRI, CIS, ISO 27k, SOC 2, PCI, FedRAMP, FFIEC, CMMC, HIPAA, DORA, SCF). Crosswalker's architecture is general-domain, but this corpus is deliberately narrowed to the [compliance & risk problem domains](/crosswalker/concepts/compliance-control-vs-obligation/) that are the primary launch use case.
</Aside>

<Aside type="caution" title="Licensing is load-bearing">
The corpus lives at repo-root `Frameworks/` and is **local-by-default** (gitignored, fail-closed). Only **public-domain US-government + MITRE** source files are committed. Copyrighted vendor files (CRI, CIS, ISO, AICPA/SOC 2, PCI, SCF) stay in `Frameworks/_licensed/` and are **never** committed. Crosswalker's *generated* notes (your own paraphrased concepts + crosswalk junctions) are derived work and can be committed; the raw vendor *text* cannot.
</Aside>

## Licensing tiers at a glance

| Tier | Meaning | Where it lives | Examples |
|---|---|---|---|
| 🟢 **Public domain** | US-gov work product or free-with-attribution; commit-safe | `Frameworks/` (committed) | NIST (CSF/800-53/800-171), MITRE (ATT&CK/D3FEND/Engage/VERIS), FedRAMP, FFIEC, HIPAA, CMMC, DORA/EU law |
| 🟡 **Restrictive CC / registration** | Free but share-alike or registration-gated; keep local to be safe | `Frameworks/_licensed/` | CIS Controls, CIS RAM, Secure Controls Framework (SCF) |
| 🔴 **Copyrighted** | Vendor IP, redistribution-restricted | `Frameworks/_licensed/` | **CRI Profile** (the spine), ISO 27001, AICPA SOC 2 / TSC, PCI DSS |

<Aside type="note" title="Format door: structured vs PDF">
A framework is only useful to Crosswalker if its content arrives **structured** (XLSX / CSV / JSON / XML), not as prose PDF. Where a framework ships only as PDF, the *machine-readable door* is noted — usually an OSCAL catalog (NIST), a CPRT export, an SCF/STRM mapping sheet, or legislative XML (EUR-Lex). PDF-only items are flagged ✂️ unless they're the sole obligation source.
</Aside>

## More CRI — what else to pull

The CRI Profile is the spine, so it's worth getting the complete set from [cyberriskinstitute.org/the-profile](https://cyberriskinstitute.org/the-profile/) (free, registration):

- **Latest version** — confirm v2.0 is current; CRI ships point releases. Grab the newest workbook + changelog.
- **Impact Tiering Questionnaire** — the scoping instrument that sizes which diagnostic statements apply.
- **Profile Workbook / extended mappings** — additional crosswalk sheets beyond what's in the core file (FS-specific regulator mappings).
- **CRI + quantification** material — if pursuing the assess-once-comply-many [unified risk model](/crosswalker/examples/unified-risk-model/) with risk scoring.

## Cleanup — non-framework files to cut

Everything marked ✂️ above (guides, templates, branding, infographics, CIS RAM methodology, PDF-only duplicates of structured data). Recommended: move them to a gitignored `Frameworks/_archive/` rather than delete, so they're reversible. They're already gitignored, so this is purely working-corpus hygiene.
